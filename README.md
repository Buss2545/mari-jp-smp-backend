# ชีวิตเมือง — วันของเรา

เกมจำลองชีวิตภาษาไทยแบบเล่นคนเดียว ได้แรงบันดาลใจจากเกมพิกเซลบนมือถือปุ่มกดยุค Java เปิดเล่นผ่านเว็บได้โดยไม่ต้องติดตั้งหรือใช้บัญชี

## วิธีเล่น

- ใช้ปุ่มลูกศรหรือ WASD เดินในเมือง หรือใช้แป้นทิศทางบนหน้าจอ
- เข้าใกล้จุดกิจกรรมแล้วกด Enter; ที่บ้านและสวนเลือกกิจกรรมได้ด้วยปุ่ม 1/2
- กด Esc เพื่อพักเกม
- ดูแลความหิว พลังงาน ความสะอาด ความสุข และความสัมพันธ์ก่อนเวลา 22:00

## เล่นในเครื่อง

เปิด `index.html` โดยตรง หรือรันเซิร์ฟเวอร์ไฟล์แบบง่าย:

```sh
python3 -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000` เกมใช้ JavaScript และภาพในโฟลเดอร์ `assets/` เท่านั้น ไม่มี backend, บัญชีผู้ใช้, dependency ภายนอก หรือคำขอเครือข่ายจากตัวเกม

## โครงสร้าง

- `index.html` — หน้าจอเกมและข้อความภาษาไทย
- `style.css` — รูปลักษณ์เครื่องเล่นพิกเซลและแผงสถานะ
- `game.js` — การเดิน เวลา กิจกรรม ความต้องการ การพัก และผลสรุปวัน
- `assets/` — แผนที่ สไปรต์ ฟอนต์ Noto Sans Thai และภาพแชร์

เว็บไซต์ GitHub Pages ให้บริการไฟล์จากราก repository โดยตรง
